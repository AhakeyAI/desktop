# AhaKey Plugin SDKs

This directory contains SDKs for building AhaKey desktop plugins.

- [`typescript`](./typescript): TypeScript SDK for JSON-RPC plugins running as
  child processes over stdin/stdout.
- [`portable-keypad`](./portable-keypad): Device configuration SDK for portable
  keypad adapters used by AhaKey plugins, starting with KeySilk / COIDEA 3-key
  + 1-knob support.
