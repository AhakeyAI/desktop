日期：2026-10-08。配套 [适配计划](./legacy-macos-ws12-adaptation-plan-2026-10-08.md)；[CSV](./legacy-macos-ws12-adaptation-wbs-2026-10-08.csv) 可导入表格或任务系统。

第一阶段共 26 个工作包，其中 1 项 Windows 联调可选。mac 单端基准 30 人日，另建议约 20% 风险预留，共约 36 人日；可选跨端联调另计 1 人日。这个数字不含文末新增的完整 WS3、语音兜底、旧功能完整性和最终发布工作包。估算含实现、必要测试、说明及评审修正，实际硬件等待和协议变化不按已知日历工期承诺。

所有条目为待开发或核验，不因原代码已有某能力就标记完成。角色未分配到个人；前置为验收依赖，界面原型等不影响设备的准备工作可提前做。外部条件多数只影响相应真机检查，不阻止模拟开发。

## 验收门和执行顺序

- G0：M01/M02 完成，旧基线可重复构建，契约及 fixture 有来源。
- G1：M03/T01/T02/T03/R01–R04/S01/S02 完成，可运行只读预览 App；连接与重连不会隐式写设备。
- G2：W01–W04/H01/H02/V01/U01/L01 完成，按能力开放可读回的写入，形成可保存的候选。
- G3：Q01/Q02/Q04/P01 完成，交付 WS1/WS2 阶段的 mac 安装候选和 PR；这不是最终用户版。Q03 不阻止 mac 单端候选，但阻止“跨端已验收”的声明。

建议顺序：M01/M02 → T01/T02/T03 与 M03 → R01 → R02/R03/R04 → S01/S02 → 写入路线与审批/Voice 路线 → U01/Q01 → Q02/Q04 → P01。Q03 在 Windows 候选就绪后加入。

## 先启动的任务

第一批执行 M01、M02、T01、M03，随后 T02、T03、R01。不等待 Windows 完工，不先向固件方索要 Harness 已有资料。确认可用键盘和 CP4D 固件后安排 G1 真机读取。

## 验收记录格式

每项记录 ID、源码 SHA、固件提交与 HEX 哈希、检查命令或人工步骤、结果、证据位置、已知限制。测试只使用隔离文件/模拟传输；真实配置写入安排在对应 HIL 阶段。不能以 ACK、静态编译或模拟测试替代读回和真机行为证明。
