# WS3 灯效保存与会话反馈补齐

基线：connect&talk f1cd1fdb2489b06ae9c66125e23fe9a98a52d4fe（PR151）。

## 本轮范围

- 亮度、单任务灯效、临时预览及停止预览沿用 CP2 的 0x88 / 0x89 / 0x8E；不引入运行时、批量写入或 0x04 保存。
- 点击时固定目标、值、基线和连接代次。保存仍执行读取基线、单项写入、读回比较；相同值也必须实际保存，读取 RAM 不能证明已持久化。
- UI 异步操作有唯一票据，在发起和完成时检查当前连接代次。关闭面板撤回完成权限并取消任务。被替代且尚未启动的任务不能发命令。
- 单项读取期间改变模式／状态选择，旧读取结果不得填入新位置草稿。保存回执明确指出保存目标，不因选择变化改写保存位置。
- 保存开始后断线、取消、超时或读回不一致，按具体亮度／模式状态保留未确认提示。本面板会话内，读取成功、其他位置保存成功不能清除；同一位置明确保存并读回一致后清除。未发写入的本地非法值或基线变化不新增不确定提示；不清除以前的不确定记录。
- 连接代次变化撤销旧成功回执。延迟的旧 onChange 不能取消已经属于当前连接的新任务。
- 草稿保留，设备事实必须重新读取；未知灯效继续只读，熄灭可保存但不可预览。
- 预览回执只说明请求被接受与固件约 10 秒时长，不宣称画面仍处于预览；停止预览只声称 ACK 已接受，不声称目视通过。
- Manager 在异步保存／单项读取返回后、发布快照之前再次检查会话。

## 验证与边界

自动验证覆盖票据失效、发起前交接、发起后交接、迟到完成、关闭面板、同位置重试与跨位置提示隔离；原协议事务测试继续验证 8E 与读回。

真机验收仅覆盖实际执行并记录的组合，不能据此关闭整个 4×9 保存矩阵和真实存储故障矩阵。保留 Codex Coffee 素材（位置8）、按键、Voice 和日常后台。可逆灯效测试结束后恢复原值，断电保持需单独记录。未确认提示只在当前设置视图会话保存，不声称跨 App 重启恢复。
