# 屏幕画面侧栏：统一三状态编辑

依据2026-11-05用户确认的新要求：屏幕查看态说明采用与按键相同的caption字号，展示当前单任务/多任务方式与进行中、等待处理、已完成三个缩略图。图片不能从当前固件导出；有本机源文件时显示缓存缩略图，并区分草稿与已核对值；无源文件的既有自定义素材显示不可回看占位，不伪造预览。

编辑态删除独立“展示方式”和任务概览块，仅在图片编辑内保留一个“展示模式”单任务/多任务分段选择。两个范围都是同样的三列状态卡片；只保留底部一个“写入键盘”，提交当前所选展示模式的图片草稿，其他范围草稿保留。选择仅改草稿；实际写入所有素材成功后再启用该模式，灯条与LCD联动。跟随终端选项保留在多任务图片区内，权限仍需用户明确授权，取消勾选与图片编辑互不替代。

## 单任务默认位置与已完成图片

固件每个物理模式仍有4个位置，用户只编辑其中3种状态：

| 用户状态 | 固件位置 |
| --- | --- |
| 进行中 | mode × 4 + 1 |
| 等待处理 | mode × 4 + 2 |
| 已完成 | mode × 4 + 3；同源内容同时写入 mode × 4 默认位置 |
| 多任务三状态 | 16、17、18，所有物理模式共用 |

默认位置上限8帧，而已完成上限12帧；已完成动画保留12帧，默认副本最多取8帧，保留首尾并均匀抽帧。静态图像字节不改变。副本与正式位置分别使用现有CRC、连接目标、冲突处理、上传和读回确认；先写三个状态，最后写默认副本。不额外放大固件容量或假设支持压缩传输；总传输量可能增加，50KB紧凑传输需求仍由固件Issue18单列。

仅在用户确认本次写入后才生成默认副本；打开页面不迁移或删除旧默认草稿。旧独立默认草稿保留在本机，但不混入当前提交。已完成写入成功而默认副本失败时，关联信息随草稿归档，重开后仍可继续补写；放弃该已完成草稿时同时清理对应待写副本。成功弹窗只在当前批次全部素材及展示方式均确认后出现。

每次素材上传可能触发App/Agent交接，所以最终展示方式必须重新明确应用，不能因为上传前是同一模式就跳过。失败或取消不声称原图已恢复，也不会自动重写其他展示范围或物理模式的草稿。

## 证据边界

1047项本地完整测试零失败，包括三状态范围隔离、12→8抽帧、单图字节保持、旧默认草稿保留、部分默认恢复重开后重试，以及图片操作后重新应用同一展示方式。安装和原生界面验收另行记录；这些模型测试不能替代实际图片上传、OLED视觉或断电保持。
