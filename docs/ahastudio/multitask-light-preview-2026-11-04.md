# 多任务灯效联动与预览

## 当前约定：与真实固件一致，常亮不闪烁

Owner最新确认：当前HW1 F99D固件不支持状态变化时闪烁，客户端虚拟灯条及侧栏示意也不闪烁。绿表示进行中、黄表示等待处理、红表示已完成，空槽熄灭；状态变化只切换颜色。此前单独增加的虚拟闪烁已移除，不能用客户端模拟冒充实体固件效果。

已核对Fireware-harness@72346b001710d573980a7d398b9e0dced8ff627c，`APP/sub_main/main.c`的`task_render_multi_leds()`直接输出固定状态色，旧CP1也明确限制了闪烁。这是当前版本的真实能力。

## 用户流程

沿用虚拟键盘选中灯条 → 右侧“修改” → “多任务灯效”，没有独立设置页。

- 虚拟键盘和右侧示意共用三会话演示时钟，初始绿/黄/红，第四段为空。每三秒部分会话切换状态色，整个过程无亮暗闪烁。
- 真实多任务按已识别会话槽位显示常亮状态色；重复快照、会话引用或焦点变化都不产生闪烁。离线或回到单任务时清除旧分段。
- 右下角白色播放图标，hover“预览到键盘”。约10秒临时预览三个会话，OLED也会临时展示模拟任务；完成或取消后清理并交还后台。
- 不添加真实会话，不发送模型请求，不写入键位/亮度/灯效Flash。结束后遵循既有交接规则，不承诺重放旧连接的多任务显示选择。
- 预览前验证能力和目标设备。已有缓存读回、App还未接管连接时，也能直接播放；没有已读回设备目标时提示先读取，不静默返回，也不放宽跨设备保护。
- 真实状态不启用灯条动画计时器；模拟演示最多2FPS，仅更新图层。窗口非前台/销毁取消只读轮询，减少动态效果开启时停止自动演示。
