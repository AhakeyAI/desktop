# 한국어판 번역 기준

이 포크의 Windows 클라이언트(`ahakeyconfig-win-java/`)와 BLE 드라이버(`BLE_tcp_bridge/`)에 들어가는 한국어 문구의 기준이에요. 새 문구를 옮길 때도 이 기준을 따라요.

## 어디에 쓰나

| 파일 | 쓰는 곳 |
|---|---|
| `src/main/resources/messages_ko.properties` | 이름 붙은 문구(`LanguageManager.text("key")`, `getString("key")`). `messages_en.properties`의 모든 키가 있어야 해요 |
| `src/main/resources/legacy_ko.properties` | 코드에 중국어로 적힌 문구(`localize("中文")`)와 연결 기록 창에서 보여 줄 중국어 로그 문장. 키는 중국어 원문 그대로예요 |
| `tools/i18n/ko_catalog.py` | 빠진 번역 찾기(`missing`), 번역 합치기(`merge`), 검사(`check`) |

`legacy_ko.properties`는 손으로 고치지 않고 JSON(`{"중국어 원문": "한국어"}`)을 만들어 `merge`로 합쳐요. 키에 공백과 줄바꿈이 많아서 손으로 고치면 깨지기 쉬워요.

## 말투

- 화면 문구는 담백한 해요체예요. 주어는 사용자나 키보드예요. `~해 드려요`, `~드릴게요`처럼 프로그램이 주어인 말은 쓰지 않아요.
- 결과는 일어난 일로 써요: `저장했어요`, `연결이 끊겼어요`, `키보드에 저장하지 못했어요`.
- 오류는 무엇이 안 됐는지와 다음에 할 일을 함께 써요: `키보드에 연결하지 못했어요. 블루투스가 켜져 있는지 확인해 주세요.`
- 버튼은 누르면 일어나는 일을 짧게 써요: `저장`, `연결`, `설치`, `다시 시도`, `키보드에 저장`.
- 제목과 라벨은 명사구로 써요: `펌웨어 관리`, `자동 대기`, `키 설명`.
- 번역투를 쓰지 않아요. 원문 어순을 그대로 옮기지 말고 한국 프로그램에서 흔히 쓰는 문장으로 다시 써요. `~를 진행합니다`, `~가 수행됩니다`, `~에 실패하였습니다` 대신 `~해요`, `~하지 못했어요`.
- 긴 줄표(`—`, `–`)를 쓰지 않아요. 쌍점, 괄호, 쉼표로 나눠요. 중국어의 전각 문장 부호(`，。：（）“”`)는 반각(`, . : ( ) ""`)으로 바꿔요.
- `선택`, `수정`, `삭제`처럼 서비스에서 흔히 쓰는 말을 그대로 써요. 일부러 `고르기`, `고치기`로 풀어 쓰지 않아요.
- 숫자와 단위: `5분`, `500ms`, `2 MiB`, `160×80`. 원문의 숫자, 버전(`v1.4.8`), 명령 코드(`0x98`), 키 이름(`F18`, `Win+H`)은 그대로 둬요.

## 꼭 지킬 것

- `%s`, `%d`, `%1$s`, `{}`, `\n` 같은 자리 표시는 개수와 순서를 그대로 둬요. 검사가 막아요.
- 여러 조각을 이어 붙이는 문구(`localize("已选择 ") + 이름 + localize("（仅本地编辑）")`)는 조각마다 앞뒤 공백과 부호를 살펴서 이어 읽었을 때 자연스러운 한국어가 되게 옮겨요.
- 키보드 OLED 화면에 보내는 글(키 설명, 화면 제목)은 펌웨어가 영어, 숫자, 기호만 표시해요. 한국어로 바꾸지 않아요.
- 로그 문장은 화면에 보이는 문장보다 짧고 사실만 써요: `[BLE] 연결 시작 ({}번째 시도)`.
