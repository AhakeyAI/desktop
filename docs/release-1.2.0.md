# AhaKey Studio 1.2.0

本版本首先支持 Windows 10/11 x64，macOS 和 Linux 保留接口。

- 新增 CH582 固件管理：安装包内置固件、官网下载固件和本地 HEX。
- 固件 `1.1.1` 支持待机时间、恢复初始化、能力查询和语音键短按/长按。
- 新增 5、10、15、30 分钟自动待机设置，可通过 USB 或 BLE 读取并保存。
- 新增只清除当前设备用户数据的恢复初始化流程，并保留固件与设备标识。
- 新增语音键短按/长按快捷键配置；默认短按 Right Alt，长按 Left Ctrl + Left Win。
- 新增软件更新提示、稍后提醒、SHA-256 校验和安装引导。
- 更新检查及固件下载统一通过 `ahakey.com/stable.json`。
- 新增内置客服二维码。
- 保留安装版原有语音识别实现与模型，避免构建覆盖造成语音回归。
