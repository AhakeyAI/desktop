# 硬件设备主页 · 布局规范

更新时间：2026-07-11  
适用范围：Settings「硬件设备」Tab 内嵌的 `AhaKeyStudioView(.embeddedClient)`（独立 Studio 窗口对齐同一结构）。

**职责边界：**「硬件设备」只做按键/部件映射画布与 Inspector；连接、改名、蓝牙占用、设备信息与 Agent 系统控制在左下角「我的设备」（`AhaKeyDeviceManagementPane` / `DeviceInfoView`）。嵌入式硬件页内原「设备信息」入口跳转到我的设备详情，不再另开一套表单。

## 1. 页面结构（定稿）

```text
┌─────────────────────────────────────────────────────────────┐
│ 左栏顶：设备名称（主标题） · 连接状态                        │
├──────────────────────────────┬──────────────────────────────┤
│ 左：键盘映射画布（顶对齐）    │ 右：元件 Tab + 当前元件配置   │
│ 左下：Agent 模式分段 + 指引   │                              │
│ 再下：硬件组装占位（待开发）  │                              │
├──────────────────────────────┴──────────────────────────────┤
│ 底栏：当前部件 · Mode · 脏计数 · 同步文案（可选，不抢标题）   │
└─────────────────────────────────────────────────────────────┘
```

| 区域 | 内容 | 规则 |
|------|------|------|
| 左栏顶 | **设备名称**为主标题（`deviceName` 或「AhaKey Mini」）；同行：连接状态 / 电量图标 | 嵌入 Settings 时也必须有；**不含** Mode 分段与连接按钮 |
| 主区左 · 中 | 键盘映射画布 | 宽度吃剩余空间；高度按键盘比例；**顶部对齐** |
| 主区左 · 下 | **Agent 模式**：Claude / Cursor / Codex / custom 分段 + 当前模式一句指引与问号 | 填画布下方留白；扫读顺序为设备 → 键盘 → 切 Agent → 右侧改部件 |
| 主区左 · 再下 | **硬件组装**占位：自定义硬件组装设计入口预留 | 仅占位与文案，无交互；后续接入组装设计能力 |
| 主区右 | 固定宽约 320–340：上元件 Tab，下配置 | Tab 始终可见；配置区滚动 |
| 底栏 | 简短同步状态 | 不抢主标题 |

## 2. 元件发现与选择

### 2.1 右侧元件 Tab（主发现路径）

Inspector 顶部列出当前代际可配置部件。用户**不点键盘也能**知道有哪些可配。

| 代际 | Tab 清单 |
|------|----------|
| 共用 | 灯条、LCD、Key1–4 |
| X1 | + 拨杆 |
| Gen2 | + 磁吸底座（拨杆等作为底座子配置，不单独占顶层 Tab） |

脏状态：对应 Tab 可挂小圆点（与画布热区脏点同源）。

### 2.2 与画布双向同步

- 点 Tab → 更新 `selectedPart` → 画布热区高亮  
- 点画布热区 → 更新 `selectedPart` → Tab 高亮  
- 配置区始终展示当前 `selectedPart` 的可编辑内容（降低「先摘要再点修改」的学习成本）

### 2.3 明确不做

- 不上左侧第三栏「部件目录」式设置页导航  
- 不把硬件主流程拆成「设备 / 键位 / 屏幕」多页  

---

## 3. 留白与密度

- 画布容器：`maxWidth: .infinity` + **顶对齐**；Mode 区放在画布下方填留白，不要用「撑满高度 + aspectRatio 垂直居中」制造空带  
- Tab 已承担发现性后，可去掉或缩短「点按灯条、屏幕…」长提示  
- Inspector 内避免大块 `Spacer` 把主操作顶到角落

## 4. Inspector 信息层级

### 标题层级

```text
1 级  元件名（inspectorHeader：Key1 / LCD / 灯条…）+ 问号帮助
2 级  模块名（InspectorSection / 折叠「更多…」）
      └ 模块内控件行
```

- **1 级**：元件标题行，含脏标记与 `InspectorHelpButton`（悬停展开、移开收起）  
- **2 级**：`InspectorSection` 常开模块，或 `AhaKeyStudioDisclosureSection` 折叠模块（标题即 2 级名）  
- 模块内可用小字标签做分区，**不升为 2 级**

### 按键模块（定稿）

| 2 级 | 语音键 | 非语音键 |
|------|--------|----------|
| 按键描述 | 描述输入 | 同左 |
| 按键配置 | 仅**语音输入方式**下拉 | 绑定方法控件 |
| 绑定方法 | 「按一下开始…」+ 控件；旁附问号（含当前输入方式注意事项） | （无，绑定在按键配置内） |
| 更多设置 | AhaType、长按阈值（折叠） | 长按固件预留（折叠） |

### 问号帮助（原理 / 指引）

- **收进问号：** 原理说明、操作指引、路线图、长 caption、纯文档文案  
- **留在正文：** 配置控件、实时状态值、脏标记、错误/约束提示  
- **不再用「更多…」承载纯说明；** 折叠区只保留仍有真实控件的内容  

### 折叠（仅控件）

与灵动岛「主区常开 + 更多…默认收起」同构，组件为 `AhaKeyStudioDisclosureSection`（嵌入色走 `AhaKeyStudioEmbeddedTheme`）。

| 元件 | 2 级常开 | 2 级折叠 |
|------|----------|----------|
| 按键 | 按键描述、按键配置；语音键另有绑定方法（在按键配置下方） | 更多设置 |
| LCD | 显示配置 | （无） |
| 灯条 X1 | 亮度、状态映射 | 更多灯效 |
| 灯条 Gen2 | 灯效配置 | 更多海洋灯 |
| 拨杆 | 实时档位、生效状态 | （无） |
| 磁吸 | 磁吸模块、模拟、未解锁套件 | （无） |

展开态不持久化；切换元件 Tab 时折叠复位。

## 5. 实现入口

- `AhaKeyStudioView`：顶栏、画布、Inspector、Tab、`inspectorHelpLines`  
- `InspectorSection`：二级模块标题 + 内容区  
- `InspectorHelpButton`：标题行问号 popover  
- `AhaKeyStudioPart`：代际可见部件过滤  
- `AhaKeyStudioDisclosureSection` / `HardwarePartTabBar`  
- Settings 嵌入：`HardwareStudioHost` → `AhaKeyStudioView(.embeddedClient)`
