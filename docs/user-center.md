# 用户中心

## 入口

- **主入口**：Studio 侧栏左下角用户卡 → 右侧「用户中心」整页。
- **引导入口**：通用设置里 AhaType 未登录时的「去用户中心登录」；硬件画布未登录开启 AhaType 时引导注册登录（嵌入模式跳转用户中心，独立窗口仍可用 Sheet）。

## 能力

- 登录 / 注册 / 退出 / 切换账号
- 资料与日/周/月额度
- 订阅充值（微信扫码）与免费券兑换
- AhaType 云端整理开关（需登录）

## 与「登录时打开」的区别

| 文案 | 位置 | 含义 |
|------|------|------|
| 用户中心 · 登录 | 侧栏用户卡 | AhaKey / AhaType **云端账号** |
| 登录时打开 | 灵动岛 → 通用 | macOS **开机登录项**，与账号无关 |

账号相关 UI **不**放在顶栏齿轮「通用设置」或灵动岛「通用」中。
