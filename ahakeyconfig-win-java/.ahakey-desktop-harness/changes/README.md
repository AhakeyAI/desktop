# 每项由 Owner 指派的变更

本目录已有内容原样保留。旧草案/排序不是当前授权。
使用 helper new/intake --owner-record 创建 DRAFT；不是创建候选列表就自动开工。
change.json schema 2 + CONTRACT.md + REFERENCES.json 记录本项范围、适用基线与证据。
一次明确范围批准后 approve 记录授权并激活；不需要 approve-baseline。
DIB record-check/submit，DLA review/request-test，Owner 返回真实结果后登记并 close。
旧 schema 1 条目仅保留历史；有未完已批准/暂停项不得强行重置，应显式迁移对账。
