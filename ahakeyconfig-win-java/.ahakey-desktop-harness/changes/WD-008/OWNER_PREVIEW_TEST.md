## 安装
1. 从托盘菜单退出当前 AhaKeyStudio；不要只关闭主窗口。保留用户 .ahakey 文件夹，不清空配置。
2. 双击交付的 AhaKeyStudio-1.0.17.exe。已有安装应使用原路径；首次安装可选择目录。本次沿用 WD006 安装配方，不要求先卸载。
3. 启动安装后的软件，到更新中心核对当前安装 1.0.17 / 本地模型版。若不是该版本，先不要测试配置保存。
4. 如果安装报错、路径异常或安全软件拦截，停止；保留弹窗与日志，不关安全防护、不反复重试。

## 正式 HW1 / HW2：分别走 USB 与蓝牙
使用已刷对应正式固件的键盘；本轮软件交测不要求自行刷写、更不代刷固件。每次只连接一把目标键盘。
HW1：x1-c582-hw1-p1-1.0.1-r001，HEX SHA256 E75BE8DEF007B7A24502E615C894D68CE454B0FD3A6139AEF45F7C697DEFC233。
HW2：x1-c582-hw2-p1-1.0.1-r001，HEX SHA256 E19F386D86282E489B595D6D5804F8F43C710429949A2F1C1B9CBCEFCBCF6A29。

1. USB：接入目标，按 WD006 原入口连接。蓝牙：拔 USB，进入正常蓝牙工作状态，点击 BLE 驱动，必须能看到原桥窗口；在桥中选目标连接，再按主软件原入口连接。
2. 先只读取：确认当前设备名称/完整固件标识正确；切换四个模式和四个键，检查已保存的动作/描述能读回；检查拨杆两位置、灯光与 OLED 设置。不应仅版本号有值、其余一直未读回。
3. 若任一配置未读回、断开、版本不符或维护锁报错，先停在这里，不保存默认值；记录时间、通道、硬件和报错。
4. 全部读取正常后，先记录原配置，修改一个普通键（例如 K2）为容易观察的测试动作，保存。应按原流程收到完成/读回确认。断开后再连，核对仍为刚才保存值，再恢复原值。
5. K1：读取当前模式实际配置，修改前记下原值；仅测试 Windows 原本支持的普通快捷键/宏。保存后重新连接核对；其他模式与未编辑项应保持。不要为了本轮测试修改 Consumer 路由。
6. 拨杆/灯光分别改一个值、保存、重新连接核对，然后恢复。OLED 选择一个可丢弃测试图片，按原上传流程完成后核对实际显示；失败保留本地图片，不删除恢复文件。
7. 断开当前键盘后，应不再显示为可操作设备；换另一把再连接，必须重新读取另一把的身份和配置，不沿用前一把的回包或草稿。按 WD006 原操作流程切换，不把 WD007 新动线作为预期。

## 最早无完整标识旧固件
分别测试 USB / BLE 连接、原本支持的基础状态与 K2-K4 保存能力。没有完整 catalog 不应伪造为正式 HW1/HW2；不要求旧固件拥有新版普通键读回、侧拨、显示或 K1 route 能力。查询超时不能当成旧固件识别成功。
先观察，只有原有操作可用且目标明确时才保存；保存后的实际效果由键盘验证，不用“写出成功”代替设备已保存。

## 结果记录
六组：HW1 USB、HW1 BLE、HW2 USB、HW2 BLE、最早旧固件 USB、最早旧固件 BLE。每组记录 pass / fail / not_executed，及连接、读取、保存、重连、换设备结果。没有对应硬件的组保持未执行，不推定通过。
失败反馈：软件版本、键盘标识或HEX身份、USB/BLE、发生时间、停在哪一步、截图/日志位置。先停止继续保存，正常断开；不清空用户资料或恢复记录，不直接刷回其他固件。用户可以先只做当前手头键盘的 BLE 读取，这是本轮最关键的首测。
