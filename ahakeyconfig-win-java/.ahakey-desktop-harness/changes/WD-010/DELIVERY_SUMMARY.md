- 更多菜单恢复云端账号及真实刷新 AhaType；登录、注册、资料/额度、记住密码、兑换和旧版微信充值流程接通。

## 使用和反馈

1. 退出当前 AhaKeyStudio 后运行上方安装包；安装/升级及整机启动尚未由 Agent 在日用环境执行。
2. 打开“更多→云端账号”，检查登录、账号刷新及关闭重开。重复点击应聚焦同一窗口；真实账号、兑换及付款仅在你实际操作后记录结果。
3. 登录后启用 AhaType，在普通文本编辑器中使用本地语音，检查等待提示、最终文字及单次输出。关闭 AhaType 可作原文对照。
