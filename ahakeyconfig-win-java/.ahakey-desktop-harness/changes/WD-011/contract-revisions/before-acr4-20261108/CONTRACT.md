## UI与用户行为
沿用左侧OLED入口→原资源选择→本地导入→预览→上传并应用，不改整体布局。
提供“原画质上传”和“快速上传”两项。原画质指当前屏幕RGB565画质，沿用CP2完整帧上传；快速固定INDEX4全动画共享16色、80x40，展开为160x80最近邻像素。导入/转换/预览不写设备；预览展示真实编码后像素、帧数、时长、资源大小及质量说明，明确点击上传才写入。
默认槽最多8帧、其他槽最多12帧，超限提示用户调整；不自动删帧、不自动继续降低分辨率。快速模式保留每帧合法时长，20..60000ms外明确报不支持而不悄悄改时长；原模式保持现有行为。
上传确认显示冻结目标、当前模式和资源；提示替换失败可能显示内置图。连接/目标变化不得继续写入旧目标。快速能力未知/不支持时说明原因，可由用户主动选择原画质重新操作，不自动更换协议写设备。允许浏览本地草稿。
复用现有进度区，展示编码字节已确认量、耗时；不把发送完当持久化成功；失败给可理解原因并保留草稿。取消/关闭若未实现设备CANCEL入口不得伪称能取消；关闭预览仅在上传前，不影响既有关闭与维护互斥。
