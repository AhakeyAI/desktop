## 1. 连接用户动线（原问题 2、4，G01–G10、G16、G18、G19）

| 场景 | 约定 |
|---|---|
| 启动软件 | 保持未连接。桥可后台启动，不弹独立桥窗口，也不据此自动连接设备。 |
| 未连接时插 USB | 仅更新候选，等用户点连接。 |
| 点击连接，只有一把 USB | 直接连接 USB，优先于 BLE。 |
| 点击连接，多把 USB | 主软件列出 USB 候选；取消保持未连接，不回退连接蓝牙。 |
| 无 USB，有唯一合格 BLE | 从系统当前已连接、名称以 AhaKey 开头的设备中确认服务和身份后直接连接。仅配对或附近可见不算当前已连接。 |
| 无 USB，多把合格 BLE | 主软件供用户选一把，不任意取第一把。 |
| 已连接 A，新插一把 USB B | 停止旧任务，断开 A 的软件配置会话，再切 B。保留 A 的系统蓝牙 HID 和打字能力。 |
| USB 拔出 | 保持断开，不自动转 BLE 或回到旧设备。 |
| 系统蓝牙 A 换 B | 保持断开，再点连接才选择当前目标。 |
| BLE 休眠、离线或桥异常造成断连 | 停止旧上传，保持断开，提示重新点击连接；不自动重连或续传。 |
| 切换到 B 后 | 读回并显示 B 的真实配置，保留 A 未保存草稿；不自动套用 A。B 读失败明确提示。 |

每次配置读写只属于一个明确设备与该次连接。后台 Hook、轮询、旧回包、重试、上传分片不得绕过连接意图或转向新目标。显示名称仅供识别，不作为唯一设备标识。
草稿已批准在切设备时保留；跨重启持久化和具体恢复入口尚未指定，不据此新增自动跨设备恢复功能。本地图片资源库的已有归属不因按键草稿隔离而改变。

## 2. 图片上传与窗口关闭（原问题 11，G02、G13、G14）

- 上传 A 时切 B：停止后续发送、结束旧任务并限时清理，再切 B；显示中止，结果未确认则如实表示，保留本地图片但绝不向 B 自动续传。
- 提供取消上传入口；取消后软件仍可操作，不无限等待桥返回。
- 主窗口 × 隐藏到托盘，上传及其他后台功能继续。
- 菜单“退出程序”才真正退出；中止上传并限时清理，不能一直等上传完成。
- 不承诺撤回已写入内容，不把“已发出取消”当成设备已回滚。固件擦写保护保持原合同，不套用图片上传的可中止规则。
- 上传性能由日志和测量定位，不在没有证据时承诺具体秒数。

## 3. 拨杆图文与审批（原问题 1、9，G11、G12、G17）

- 图形位置跟随键盘实际回传；文字显示当前位置及该位置已保存动作，如“上拨 · 自动批准”“下拨 · Ctrl+C”。宏显示“下拨 · 自定义宏”，详细内容在编辑区。
- 编辑区完整展示上下绑定。草稿标未保存，左侧图保持设备已保存值；保存并读回确认才更新。失败保留草稿并提示。
- 只有当前实际位置的已确认保存绑定为“自动批准”才启用自动批准。自定义、无动作或配置未知均不按物理位置推定自动批准。
- 移除 AhaKey 自有确认窗和额外 ask，保留平台自身审批；不是把所有请求自动批准。
- Hook、对外状态接口和 UI 必须保持语义一致；不得只修文字却保留错误审批行为。
- 断开或未读回时不得冒充实时配置。具体未知态文案与显示形式由实现提案明确，不能填默认值冒充设备回传。

## 4. 按键编辑与模拟（原问题 5、6，G15）

- K1–K4 所有快捷键和宏步骤选键入口置顶 F18。保留本地模型版“本地语音输入”提示边界，不自动改写用户键值或 onboarding 配置。
- 点击模拟立即执行当前编辑动作，无倒计时、不主动切换窗口、不要求先写入设备。宏执行当前完整宏，不能误用残留快捷键。
- 按动作快照执行，正确处理延时、按下、抬起与释放；系统发送成功不等于目标应用已完成操作。模拟不写设备配置。

## 5. 版本读取与菜单（原问题 7、8，G20）

- 调查固件完整版本请求、传输、接收、解析、展示全过程。当前“并发命令违反固件 stop-and-wait，导致身份请求被丢弃”是代码与日志支持的假设，尚非硬件复测结论。
- 区分基础固件版本、完整身份、未知/读取失败；不能把读失败默认成 v1.0，也不能把软件发行版本与固件版本混用。
- 更多菜单删除“重新连接设备”“清空 OLED 预览”；云端账号、刷新 AhaType 前移；切换语言、退出程序最后。设备管理和查看版本等入口使用同一实际软件发行身份。
- 云端账号目前无点击处理，刷新目前只更新本地状态。这两项功能缺口另排，本轮只调整菜单，不宣称新增云端功能。
