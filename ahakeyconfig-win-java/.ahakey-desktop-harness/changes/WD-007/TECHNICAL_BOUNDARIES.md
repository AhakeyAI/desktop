# WD-007 技术边界与实现裁定

授权依据：G01–G20 与 2026-10-31 Owner 完整流程/本地模型 EXE 指派。以下为满足既定动线的内部设计，不增加用户功能，不改 Firmware。

## 桥和单目标会话

Java 协调器持有连接意图、目标身份和单调会话代次；列举设备不创建配置连接。USB使用精确设备路径，BLE使用Windows设备ID/地址，不按显示名去重。同目标新的连接也产生新代次。旧连接回调、排队写、ACK、取消finalizer不能影响新代次。
新增仅回环的版本化 Java↔随包桥控制面，提供 hello/version、列举当前系统连接候选、显式connect、disconnect/cancel、状态及请求错误；所有请求带请求ID，涉及会话的操作带目标和代次。连接需再核对系统连接及服务身份；旧桥/不匹配版本不能降级成任意自动选中。
桥随主程序以studio后台模式启动，禁启动时按旧配置MAC自动扫描连接及自行重连。保留原R13的连接/发现代次、CCCD确认及限时串行写。独立软件正常使用不需桥窗，现有诊断入口可保留但不能另建不受协调器管控会话。
桥数据端点移至私有回环端点，避免与9000审批端点争用。具体端口可由启动时分配/传递，必须进程归属可验证、冲突明确失败，不杀占用端口的任意进程。受控补丁及构建可扩展到必要桥协议源文件，但不修改只读基线源或target历史快照。

## 固件请求调度与完整版本

所有当前会话的命令发送共享完整请求响应时序，不能只锁write后让另一请求穿入。覆盖Hook刷新、轮询、初始化、0x9F、配置保存、上传及桥内部自动状态查询。根据实际固件实现区分有回包和无回包，不虚构ACK，不把GATT完成当业务ACK。
超时后同opcode迟到回复不能冒充下一请求；采用可证明的会话失效/隔离策略。记录排队、实际write、回应/超时和target/session/request/opcode。未读到完整身份显示未知或基础版本，不默认v1.0，不擅改固件的版本常量。

## 保存事实与审批兼容

独立保存当前设备、代次、实际位置、上下绑定、读回确认态的设备快照；草稿不改变该快照，保存失败或读回不一致不冒充已生效。离线/未知默认不自动批准。图形位置只由物理状态驱动。
Hook不弹自有确认，不附加ask/deny；非明确auto走消费者原生审批路径，不能一律allow。状态事件仍保留，Cursor灯色不在本轮修改。
Kimi已有消费者data[6]=0表示auto，非0的有效status会附加manual_lock。为满足“其他情况保留平台原生审批”，非auto使用已有status不可用形态使消费者返回None，而不是返1强制锁。由Java统一拥有9000审批兼容端点，USB/BLE均从已确认绑定计算；真实物理状态字段不得被改义。必须以实际消费者代码/回放验证，不能只测试输出JSON。

## 上传取消、设备恢复与退出

取消令牌必须到发送等待、每片及COMMIT前；限时收口不能依赖同步Native I/O自行返回。清理仅涉及软件持有资源，绝不按进程名杀第三方/用户实例。
实际固件没有上传ABORT或闲置自动取消，释放配置GATT不保证真实HID链路失效。取消后应保留该设备待恢复/结果未知状态，防止在同设备未清理事务上继续写；必要时提示拔插/重启键盘或真实链路重建。UI仍可操作，其他目标可按G02切换。不得发送畸形CHUNK、COMMIT或虚构ABORT来清状态，不承诺重新打开GATT即恢复。
COMMIT已尝试而确认缺失显示结果未知，不显示撤回。×仅托盘隐藏继续上传；菜单退出取消上传、有界后台清理，但保持固件擦写维护保护。

## 草稿、模拟和低风险呈现

草稿按可靠设备身份保留于本次进程，不自动跨设备套用；本轮不承诺跨重启恢复。返回A先读实际配置再提供保留的未保存草稿，不能把草稿冒充设备事实。身份不明时不合并。
模拟快照当前动作，立即开始、不切焦点；宏延时沿用实际单位(param*3ms)，异常/取消/finally释放本次按下的键，检查SendInput部分失败。测试用注入sender，不向Owner桌面发真实按键。
未知状态明确显示未连接/读取中/读取失败，不默认下拨或自动批准。无候选时提示USB插入或Windows连接AhaKey蓝牙，允许刷新/取消；不自己开启系统配对。

## 构建与测试边界

版本暂定1.0.13（比已测试1.0.12新，Lite与Local Model仍共用同一版本序列）；本次只交付local-model。采用现有受审package-local-model脚本、已校验verified-models和JNI，隔离构建目录。保留现有UpgradeCode、安装位置恢复与发行签名机制，不初始化新签名密钥。无需Owner再选择形态。
机器验证不能替代系统BLE/HID共存、实物拨杆、真语音、清洁安装/原路径升级与烧录验收。交付包如尚缺正式UAT应如实标Preview待测，不能为了打包伪造CLOSED或Owner PASS。
