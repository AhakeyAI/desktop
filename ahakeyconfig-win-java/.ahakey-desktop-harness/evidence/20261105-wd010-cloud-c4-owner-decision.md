# WD010 Cloud C4：兑换窗口及异常处理

日期：2026-11-05（Asia/Shanghai）。
Owner选择：
> 采用这套兑换流程（推荐）

确认所展示流程：独立兑换码窗口显示当前账号、输入框及“兑换将计入当前账号”，取消/确认兑换；提交显示正在兑换并防止重复，关闭再打开查看同一次操作。明确成功后刷新权益；成功但刷新失败单独说明并提供刷新账号。超时显示结果暂无法确认，建议先刷新账号查看权益，不自动重发；兑换码已使用不等于本次成功。明确业务错误在窗口内显示并保留输入。
确认范围为产品交互，不证明服务端幂等性或真实兑换结果，不授权测试消耗真实兑换码。保持CHANGE/DRAFT。
