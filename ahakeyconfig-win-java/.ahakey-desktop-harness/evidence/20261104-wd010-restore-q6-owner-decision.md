# WD010 Restore Grill Q6：允许关闭窗口并继续查询

问题：恢复过程中能否关闭进度窗口？固件开始恢复后不能取消。建议允许关闭，并明确提示“关闭窗口不会停止设备恢复”；软件继续查询，再点菜单打开同一个进度窗口，不重新执行恢复。

Owner 选择：
> 允许关闭窗口，后台继续查询（推荐）

决定：进度/结果窗口可关闭；恢复任务与窗口生命周期分离，窗口关闭不取消恢复、不停止当前应用的状态查询，再次打开显示同一任务。关闭整个应用无法保证继续查询，但不能取消已开始的固件操作；下次连接只查询状态，不自动发起恢复。
