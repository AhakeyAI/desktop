# WD010 Cloud C3：记住密码、保持登录及主动退出

日期：2026-11-05（Asia/Shanghai）。
Owner 对所展示的 C3 会话/回填方案选择：
> 采用这套行为（推荐）

确认：关闭账号窗口不退出；重新打开软件可恢复仍有效的登录态，与是否勾选记住密码分开。默认不勾记住密码；勾选仅在下次需要登录时回填，不自动提交；取消勾选删除已保存密码，不注销当前会话。主动退出清除本地登录态和账号资料，保留此前已勾选的密码回填，必须手动点击登录；登录过期不自动用密码重登。
密码采用受保护的保存方案，不能沿用历史明文保存；本地保存/清除失败如实提示。本记录确认产品行为，不代替安全存储实现验证、线上会话验证或完整 Contract 批准。WD010 保持 CHANGE/DRAFT。
