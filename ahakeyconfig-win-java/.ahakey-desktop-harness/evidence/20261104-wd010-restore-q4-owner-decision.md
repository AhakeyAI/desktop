# WD010 Restore Grill Q4：不可用原因反馈

Owner 对“保持可点击并明确说明不能恢复的原因”选择：
> 保持可点击，明确说明无法恢复的原因（推荐）

决定：恢复入口保持可见、可点击；未连接、已证实不支持、可观察的保存/上传等忙碌状态在发起前明确提示，不发送恢复命令。外部供电等条件由可靠设备状态和固件最终裁决。已知缺少供电时提示接USB供电。
事实约束：当前恢复回复 result=1 是通用拒绝/错误，不能仅凭该字节声称确切原因。没有可靠原因证据时显示“设备拒绝恢复，请检查USB供电或设备忙碌状态”等建议，不谎称已检测出缺供电。不通过破坏性试发探测旧固件能力。
仍为CHANGE，未授权实现或设备操作。
