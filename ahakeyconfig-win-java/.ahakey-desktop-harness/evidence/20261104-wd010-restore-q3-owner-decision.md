# WD010 Restore Grill Q3：未保存草稿

问题：如果软件里还有未保存的设备配置，恢复时怎么处理？建议在同一个确认弹窗追加“未保存的设备配置也将丢弃”；确认后直接恢复，取消则保留草稿。恢复后以设备读回值为准，旧草稿不自动写回。

Owner 选择：
> 同一弹窗说明，确认即丢弃并恢复（推荐）

决定：不要求用户先保存或另行丢弃；同一恢复弹窗提示影响，取消原样保留。确认发起后丢弃恢复目标设备的旧配置草稿，恢复后重新读取设备；不得自动回写旧草稿。发起前须重新核对目标和可观察前置条件，防止确认期间切换设备。不扩大到云端账号或无关本地文件删除。
仍为 CHANGE/DRAFT，尚未授权生产实现或现在操作设备。
