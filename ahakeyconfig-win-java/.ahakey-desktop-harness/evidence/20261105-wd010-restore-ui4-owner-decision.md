# WD010 Restore UI4：目标设备配置只读

日期：2026-11-05（Asia/Shanghai）。
问题：恢复进行中、结果尚未确认或配置还没同步完成时，目标设备配置页面只读；按键/宏、拨杆、灯光、显示仍可查看，不能编辑/保存/上传/预览写入，显示原因和查看进度；完成并同步后恢复编辑，云端账号等无关功能照常可用。

Owner 选择：
> 目标设备配置暂时只读（推荐）

决定：采用上述只读行为，避免设备读回覆盖恢复期间新编辑的草稿。此处只读仅针对恢复目标设备的配置操作，不将无关账号等功能一并禁用。明确拒绝且未开始恢复不能永久锁死；查询/读回/经用户确认重试仍必须可进行。
对应状态文案继承已展示方案。锁的实现、目标身份、拒绝/断连后的精确生命周期及另一台设备的处理仍需技术核验，不将本决定当作已实现或测试通过。
