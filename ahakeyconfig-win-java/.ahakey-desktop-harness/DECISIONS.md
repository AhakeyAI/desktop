## 试运行实现选择（不是另一次 Owner 产品批准）

一次 BASELINE_ADOPT + 日常 CONTRACT ⇄ BUILD_VERIFY；Grill 贯穿 Contract，不机械串联全部 Stage。等待/审查/UAT 是状态或活动，不另加阶段。

使用 JSON 保存可机读状态以免依赖 PyYAML。少量 helper 检查批准输入哈希、单一活跃任务与证据记录，不能代替真实批准或真机结果。工具/模板细节可根据首轮实际问题经 Owner 批准调整。

尚未确认：具体本地源码路径/提交、Firmware 路径、当前真实 UI 数值、核心旅程明细、正式协议文件位置、具体版本支持表、首项 Feature。不得填造。
