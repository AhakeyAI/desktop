The installer custom action contains the upstream x64 SfxCA bootstrap and
WixToolset.Dtf.WindowsInstaller.dll. No upstream source code was modified;
the custom action is assembled using the official MakeSfxCA packager.
The WiX 3.14 candle/light toolchain is retained; only the custom action's DTF
inputs use the version below.

Official packages:
https://www.nuget.org/packages/WixToolset.Dtf.CustomAction/5.0.2
https://www.nuget.org/packages/WixToolset.Dtf.WindowsInstaller/5.0.2

Exact package and extracted-file SHA256/SHA512 identities are recorded in
dtf-toolchain.json. Packaging requires an explicit local DtfRoot, validates
these bytes before use, and never downloads dependencies automatically.
