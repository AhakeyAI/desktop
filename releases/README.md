# Releases

## 这个目录是什么？

发布说明与发布边界的占位入口目录。

## 当前包含什么？

- 当前只保留本 README，作为发布约定入口
- 更完整的发布原则、发布物范围和仓库边界说明见 [`docs/releases.md`](../docs/releases.md)

## 当前不包含什么？

- `exe`
- `msi`
- `dmg`
- 发布压缩包
- 打包输出目录
- 任何安装包二进制

## 如何使用这个目录

当前不要把安装包、构建产物或本地打包缓存提交到这里。
如果需要更新发布约定，请优先修改 [`docs/releases.md`](../docs/releases.md)，再视情况同步这里的简要说明。

## GitHub Releases 对应发布物

真正的安装包与发布二进制应上传到 GitHub Releases，而不是保存在本目录或源码仓库中。
