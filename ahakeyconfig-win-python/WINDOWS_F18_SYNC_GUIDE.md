# Windows F18 同步口径

更新时间：2026-04-14

这份文档用于统一“语音键 / F18 / HID 值 / Windows 监听值”的说法，避免把不同层级的值混用。

## 1. 最稳的同步说法

和 Windows 同事同步时，直接按下面这套说最稳：

1. 产品层统一名称

```text
语音键 = F18
```

2. 设备协议层统一值

```text
F18 在设备配置里保存为 HID Usage ID 0x6D
```

3. Windows 软件层监听规则

如果 Windows 端是在监听系统键盘事件：

- 使用 `VK_F18`
- 它的值是 `0x81`

## 2. 为什么要这样区分

- `F18` 是产品和用户可理解的统一名称。
- `0x6D` 是设备配置层保存的 HID Usage ID。
- `0x81` 是 Windows 系统键盘事件层里 `VK_F18` 对应的虚拟键值。

所以，不建议直接对 Windows 监听同事说“监听 0x6D”。

最稳的表达应该是：

```text
对外统一叫 F18；
设备配置层保存 0x6D；
Windows 监听层使用 VK_F18，也就是 0x81。
```

## 3. 一句话版本

```text
语音键产品名统一叫 F18，设备协议里存 HID Usage ID 0x6D，Windows 如果监听系统键盘事件就监听 VK_F18（0x81）。
```
